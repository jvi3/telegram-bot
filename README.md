# Китайский дурак для Telegram — by Кащей

Игра открывается прямо в Telegram через бота. Друга зовёшь кнопкой «Пригласить друга»: он нажимает ссылку, бот присылает кнопку «Сесть за стол», и вы играете. Есть тренировка с ботами, ботов можно посадить и к друзьям.

## Что внутри

| Файл | Что это |
|---|---|
| `server.js` | Сервер: хранит партии, рассылает ходы, отвечает в боте |
| `rules.js` | Правила игры и логика ботов |
| `index.html` | Сама игра, которую видно в Telegram |
| `package.json` | Список того, что нужно для запуска |

Карты соперников сервер никому не отправляет: каждый получает только свою руку.

## Как запустить (примерно 15 минут)

### Шаг 1. Новый токен бота

Старый токен уже засветился в чате, поэтому его надо сменить.

1. Открой **@BotFather** в Telegram.
2. Отправь `/revoke`, выбери своего бота.
3. Скопируй новый токен в заметки. **Никому не присылай**, даже в чат с Claude.

### Шаг 2. Выложить код на GitHub

1. Зарегистрируйся на [github.com](https://github.com), если ещё нет аккаунта.
2. Справа вверху нажми **+**, затем **New repository**.
3. Назови, например, `durak`. Можно поставить **Private**. Нажми **Create repository**.
4. На странице репозитория нажми **uploading an existing file**.
5. Распакуй архив и перетащи в окно **всё содержимое папки** `durak-tg`: все файлы: `server.js`, `rules.js`, `index.html`, `package.json`, `README.md`.
6. Нажми **Commit changes**.

> Проверь, что `package.json` лежит в корне репозитория, а не внутри ещё одной папки.

### Шаг 3. Запустить сервер на Render

1. Зарегистрируйся на [render.com](https://render.com). Удобнее всего через **Sign in with GitHub**.
2. Нажми **New +**, затем **Web Service**.
3. Выбери свой репозиторий `durak` и дай Render к нему доступ, если спросит.
4. Заполни поля:
   - **Name**: любое, например `kaschey-durak`
   - **Region**: **Frankfurt (EU Central)**, это ближе всего к тебе
   - **Runtime / Language**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free`
5. Ниже, в разделе **Environment Variables**, нажми **Add Environment Variable**:
   - **Key**: `BOT_TOKEN`
   - **Value**: твой новый токен из шага 1
6. Нажми **Deploy Web Service** и подожди 2–3 минуты.
7. В логах должна появиться строчка `Бот @твой_бот готов`. Значит, всё работает.

### Шаг 4. Играть

1. Открой своего бота в Telegram и отправь `/start`.
2. Нажми **🃏 Играть**. Кнопка «Играть» появится и слева от поля ввода.
3. Нажми **Создать комнату**, затем **Пригласить друга** и выбери друга в списке чатов.
4. Друг жмёт ссылку, затем **Сесть за стол**, а ты — **Раздать карты**.

## Админ-панель

1. Напиши боту `/myid`: он пришлёт твой Telegram ID (только цифры).
2. На Render: **Environment**, затем **Add Environment Variable**. **Key:** `ADMIN_IDS`, **Value:** твой ID. Несколько админов пиши через запятую.
3. **Save Changes**, и после перезапуска напиши боту `/admin`.

В панели: статистика, открытые комнаты (можно закрыть), последние игроки с их ID, баны, рассылка всем игрокам и режим техработ (новые игры не создаются, начатые доигрываются). Команды: `/ban ID`, `/unban ID`.

Игроки, рейтинг, баны и счётчик партий хранятся в базе данных (см. ниже). Без базы они стираются, когда сервер засыпает.

## База данных (бесплатно, Neon)

Нужна, чтобы рейтинг, игроки и баны не пропадали, когда сервер засыпает.

1. Зайди на [neon.com](https://neon.com) и нажми **Sign up**. Удобно войти через GitHub.
2. Создай проект: любое имя, например `durak`. **Region:** выбери **Europe (Frankfurt)**.
3. На странице проекта нажми **Connect**. Скопируй строку подключения: она начинается с `postgresql://`.
4. Эта строка содержит пароль от базы. **Никуда её не присылай**, только в Render.
5. На Render открой **Environment** и добавь переменную: **Key** `DATABASE_URL`, **Value** — скопированная строка. Нажми **Save Changes**.
6. В логах после перезапуска должно появиться `База данных подключена`.

Таблицу в базе сервер создаёт сам.

## Что важно знать

- **Бесплатный Render засыпает** после 15 минут без запросов. Первый `/start` после сна может отвечать до минуты, это нормально.
- **При засыпании или перезапуске сервера текущие партии пропадают.** Обычно это случается, только если все ушли.
- Если захочется, чтобы сервер не засыпал, на Render есть тариф Starter (около $7 в месяц). Можно переехать и на другой хостинг, код от этого не меняется.
- Обновить игру просто: заменяешь файлы в репозитории на GitHub, и Render сам перезапустит сервер с новой версией.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| В логах Render `Не задан BOT_TOKEN` | Проверь шаг 3.5: ключ должен быть ровно `BOT_TOKEN` |
| В логах `Telegram getMe: Unauthorized` | Токен неверный или старый. Возьми новый у @BotFather |
| Бот молчит на `/start` | Подожди минуту (сервер просыпается), потом отправь ещё раз |
| В игре написано «Открой игру через Telegram-бота» | Игру надо открывать кнопкой в боте, а не ссылкой в браузере |

## Проверить у себя на компьютере (необязательно)

Нужен установленный [Node.js](https://nodejs.org) 18 или новее.

```
npm install
npm run dev
```

Открой `http://localhost:3000` в двух окнах браузера. В режиме `dev` вход через Telegram не нужен, бот при этом не работает.
